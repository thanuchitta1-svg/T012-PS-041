# Parking Garage Billing System

## Project Information
- Project ID: PS-041
- Project Name: Parking Garage Billing System
- Programming Language: Python 3.12.10

## Project Description
The Parking Garage Billing System is a command-line application developed using Python.

It helps manage vehicle parking, parking fee calculation, monthly pass registration, EV parking and parking slot availability.

## Features
1. Vehicle Entry
2. Vehicle Exit
3. Parking Fee Calculation
4. Monthly Pass Registration
5. EV Parking
6. Parking Slot Availability
7. Exit System

## Technologies Used
- Python 3.12.10
- Visual Studio Code

## How to Run the Project
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `python main.py`
