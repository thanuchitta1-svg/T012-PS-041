# DECISION LOG

## Project: Parking Garage Billing System
**Project ID:** PS-041  
**Team ID:** T012  
**Programming Language:** Python 3.12

### Decision 1: Programming Language
Python 3.12 was selected because it supports clear and structured programming and provides built-in testing capabilities.

### Decision 2: Development Environment
Visual Studio Code was selected as the development environment for writing, running and testing Python code.

### Decision 3: Menu-Driven Approach
A command-line menu approach was selected to allow operators to perform parking operations through simple numbered options.

### Decision 4: Parking Bay Categories
Four parking bay categories were selected: TWO_WHEELER, CAR, SUV and EV_CAR, following the project requirements.

### Decision 5: Billing Calculation
Tariff-based billing was selected to calculate parking fees according to vehicle type and parking duration.

### Decision 6: Monthly Pass Management
Monthly passes are linked to individual vehicle registration numbers and cover the specified daily time period.

### Decision 7: EV Charging
EV energy charges and idle fees are calculated separately according to the specified charging rules.

### Decision 8: Tax Calculation
Separate GST rates are applied to parking and idle fees and EV energy charges.

### Decision 9: Testing Approach
Python's unittest framework was selected for writing and executing automated test cases.

### Decision 10: Version Control
GitHub was selected to maintain the project repository and store project documentation and source code.
